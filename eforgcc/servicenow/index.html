Approach

Each rollout wave follows phases with exit gates.

Phase 1

Initiate

  • Team and stakeholder alignment
  • Initial timeline and workshop plan
OutputGate: timelines and outcomes signed off
Phase 2

Plan

  • Customer workshops
  • Requirements and traceability matrix
  • Story creation and refinement
  • Sprint roadmap and customer approval
OutputGate: sprint roadmap signed off
Phase 3

Execute

  • Sprint planning
  • Configuration and development
  • Unit testing and peer review
  • Sprint review, demo and customer feedback
OutputGate: build complete and unit tested
Phase 4

Transition

  • User acceptance testing
  • Go-live readiness and runbook
  • Knowledge transfer
  • Go-live and hypercare support
OutputGate: UAT signed off; hypercare exit criteria met
Phase 5

Close

  • Lessons learned
  • Customer retrospective
  • Customer closure meeting
  • Documentation archive
OutputGate: run handover accepted
